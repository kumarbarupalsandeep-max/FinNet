## 1. FinNet kya hai?
FinNet ek aisa tool ho sakta hai jo company ko bataye ki cloud, software aur technology par kitna paisa kharch ho raha hai. Ye sirf bills nahi dikhayega; ye bhi batayega ki paisa kis team ya project ne kharch kiya aur kahan cost kam ho sakti hai.

## 2. Kiske kaam aayega?
- Finance team: budget aur actual kharch compare karne ke liye.
- Developers / Cloud team: mehngi services aur waste dhoondhne ke liye.
- Managers: project ke hisaab se technology cost samajhne ke liye.
- Procurement team: software subscriptions aur renewals track karne ke liye.

## 3. Similar tools se kya seekhein?
FinOps Foundation cloud cost ko samajhne, zimmedari assign karne aur cost optimize karne par focus karta hai. Microsoft ki FinOps guidance mein budgets, forecasts, cost allocation aur optimization jaise topics hain. Isse seekh milti hai ki product mein sirf charts nahi, balki clear actions bhi hone chahiye.

## 4. Main features
1. **Cost dashboard:** Total kharch, pichhle mahine se difference aur budget status.
2. **Cost by team/project:** Kis team ya project ka kitna kharch hai.
3. **Budget alerts:** Budget limit paas aane par warning.
4. **Unexpected cost alerts:** Achanak bill badhne par notification.
5. **Forecast:** Maujooda trend ke hisaab se agle mahine ka andaza.
6. **Savings suggestions:** Unused ya over-sized resources ko check karne ki list.
7. **Software renewal tracker:** Subscription ki cost aur renewal date.
8. **Reports:** CSV/PDF export aur manager-friendly summary.
9. **Audit history:** Kisne budget ya allocation rule badla.
10. **Integrations:** Shuruat mein CSV import; baad mein cloud billing connectors.

## 5. Pages / screens
Login, Overview Dashboard, Costs, Teams & Projects, Budgets, Forecasts, Alerts, Savings Recommendations, Software Subscriptions, Reports, Integrations, Users & Roles, Audit Log, Settings, Help.

## 6. Kaise kaam karega?
Pehle user bill ki file upload karega. FinNet data check karega, galat rows dikhayega, phir cost ko team/project ke saath map karega. Dashboard par user total kharch dekhega aur kisi alert par action assign kar sakega.

## 7. Technical planning
Data ke liye Cost Record, Provider Account, Team, Project, Budget, Forecast, Alert aur Recommendation jaise records honge. Original bill data ko alag rakhein, taaki calculation dobara check ki ja sake. Currency conversion ka rate aur date bhi save honi chahiye.

## 8. Security
Har company ka data doosri company se alag rahe. Roles ke hisaab se access dein. API keys ko code ya browser mein expose na karein. Har important change ka audit record rakhein.

## 9. Development phases
- Phase 1: CSV upload, cost dashboard, team/project allocation.
- Phase 2: Budgets, forecasts, alerts aur reports.
- Phase 3: Cloud integrations, subscription tracking aur savings workflow.
- Phase 4: Advanced recommendations aur verified savings reports.

## 10. Success kaise naapenge?
Kitna kharch owner ke saath map hua, report banane mein kitna time laga, alerts kitne useful nikle, forecast kitna sahi raha aur kitni savings ko actual data se verify kiya gaya.

## 11. Risks
Bill formats alag ho sakte hain; unke liye validation chahiye. Galat allocation se report par bharosa kam hoga. “Savings” tabhi claim karein jab before/after data se proof ho.

## 12. Original product idea
FinNet ko “cost se action tak” ka tool banayein: alert aaye, owner assign ho, action complete ho aur baad mein savings verify ho.
